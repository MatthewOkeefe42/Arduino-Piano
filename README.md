# Children-s-Piano

The Piano App was originally developed for an Arduino board fit with buttons (for the keys), LED’s, and an OLED screen. 
The project was developed for my Sophomore Capstone as a way to encourage children to experiment with musical instruments and become familiar with basic music theory. 
Each note pressed would trigger an animation on the OLED screen that would display text declaring the specific note being played and a short animation of a Pokémon or animal that was alliteratively connected to the note. 
For example, pressing the A note would trigger an animation of an Alpaca
